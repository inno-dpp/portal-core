Keycloak Identity Provider

Default Keycloak instance used to provision organization groups and first users during onboarding. These values pre-fill the Keycloak card on the onboarding sync form, where they can still be overridden per organization. Values saved here are stored encrypted in the database and override the environment variables KEYCLOAK_BASE_URL, KEYCLOAK_REALM, KEYCLOAK_ADMIN_CLIENT_ID and KEYCLOAK_ADMIN_CLIENT_SECRET without a restart.

Leave empty to revert to the environment default: http://localhost:8081
